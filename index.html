편집 설정

글꼴

폰트·크기·글자색은 기본적으로 드래그한 글자에 적용됩니다. ‘글꼴 적용’은 현재 설정값을 페이지 전체에 일괄 적용합니다.

문단

간격

글자를 선택하면 선택 영역에, 선택하지 않으면 현재 슬롯의 모든 페이지에 실시간으로 적용됩니다.

사용자 폰트

문서 템플릿

현재 템플릿 세부 설정

이 값은 현재 선택한 템플릿에만 저장됩니다. 다른 템플릿으로 바꾸면 해당 템플릿의 설정을 따로 불러옵니다.

문서 비율은 편집 화면·미리보기·이미지/PDF 저장에 함께 반영됩니다.

본문 배치

2단·3단은 한 페이지 안에서 본문을 신문/책처럼 나눕니다. 세로쓰기에서는 단 나누기를 1단으로 자동 표시합니다.
