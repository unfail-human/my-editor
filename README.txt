MY EDITOR V7

변경사항
- 본문 상단 툴바를 최소화
- 오른쪽 패널을 탭 3개로 분리:
  1. 글씨 편집
  2. 문서 배경
  3. 문서 설정
- 폰트/크기/굵게/기울임/밑줄/취소선/색/형광펜/정렬/자간/행간/문단 간격을 오른쪽으로 이동
- 문서 배경 기능을 별도 탭으로 분리
- 슬롯/쪽번호/문서 정보를 문서 설정 탭으로 이동
- PNG/JPG/PDF 저장용 문서를 화면 문서와 별도로 복제하여 전체 높이를 계산하도록 변경
  -> 화면용 스크롤/고정 높이 때문에 글씨가 잘리는 문제를 줄임

GitHub에서는 index.html, style.css, script.js만 교체하면 됩니다.
