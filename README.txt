카드형 레이아웃 수정
대상:
1. 카드형 3:2
2. 와이드 카드 16:9
3. 미니 카드 4:3
4. 티켓형

핵심 수정
- 제목과 소제목이 정확히 같은 시작선/끝선 사용
- 제목과 소제목을 하나의 세로 헤딩 블록으로 묶음
- 소제목은 제목 바로 아래 작은 간격으로 배치
- 제목/소제목의 별도 좌우 위치값 제거
- 본문도 동일한 콘텐츠 폭 안에서 시작
- 가로/세로 방향별 상단 위치 별도 계산
- 오래된 자동 기본값은 새 카드 레이아웃 기본값으로 자동 이관

기본 제목 크기
- 카드형 3:2: 28px
- 와이드 카드 16:9: 28px
- 미니 카드 4:3: 26px
- 티켓형: 28px
