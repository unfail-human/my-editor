본문 위치
- 이제 편집기 전체가 아니라 본문 글 블록만 이동
- p / blockquote / 목록 / 일반 본문 div 등만 좌우 이동
- 무단 구분 기호와 구분용 공백은 본문 위치 변경의 영향을 받지 않음
- 기본값: 왼쪽 4%
- 범위 확대: 왼쪽 20% ~ 오른쪽 8%
- 새 문단을 입력해도 즉시 현재 본문 위치 적용

기호 정렬
- 기호 > 무단 구분에 '기호 정렬' 추가
- 왼쪽 / 가운데 / 오른쪽
- 기본값은 가운데
- 기존에 넣은 기호에도 즉시 적용
- 구분선 사용 시에도 정렬에 맞춰 기호 위치 조정

자동 페이지 / 저장 / 미리보기
- 기존 동작 유지
- 본문 위치 변경 뒤 페이지 재계산 유지
