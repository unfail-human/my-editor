MY EDITOR V54

핵심 수정
- 제목/소제목/본문을 동일한 콘텐츠 좌우 기준선으로 통일
- 제목 위치를 바꿔도 본문 시작점이 같은 축을 사용
- 제목/소제목 사이 및 본문과의 간격 재조정
- 가로/세로 방향 모두 별도 레이아웃 정규화
- 1단/2단/3단 변경 시 구분 장식이 현재 단 안에서 중앙 정렬
- 기존 CSS가 새 문서 레이아웃을 덮어쓰던 충돌 규칙을 강제로 정리
- 문서 내용은 종이 영역 밖으로 보이지 않도록 overflow 고정

템플릿 리사이징
- 템플릿마다 편집 화면의 실제 표시 크기가 확실히 다르게 보이도록 변경
- A4 기준
- A5/엽서/카드/미니카드/정사각형 등은 실제로 작아짐
- 레터형은 A4와 다른 비율/크기
- 와이드 카드/티켓은 가로 폭이 확실하게 드러남
- 세로/가로 방향 전환 시 종이 자체가 즉시 리사이징

자동 페이지
- 편집 입력 전에 현재 레이아웃을 다시 계산
- 템플릿/방향/단 수 변경 후 페이지 재배치
- 넘친 내용은 종이 밖에 노출하지 않고 다음 자동 페이지에서 표시
