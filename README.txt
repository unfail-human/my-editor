MY EDITOR V17

변경사항
- 전체 수정 / 일부 수정 모드 제거
- 기본 동작은 항상 선택 영역 수정
- 글꼴 파트:
  - 글꼴 적용: 현재 페이지 전체에 글꼴/크기/글자색 적용
  - 기본 서식으로: Pretendard 12pt / #3f3d3b / 기본 간격
- 간격 파트:
  - 선택 영역은 슬라이더 즉시 적용
  - 간격 적용 버튼은 현재 페이지 전체에 적용
- 사용자 추가 폰트:
  - IndexedDB 로드 로직 재작성
  - FontFace를 직접 로드한 뒤 드롭다운에 등록
  - 선택 영역과 페이지 전체 모두 적용 가능
- 들여쓰기/내어쓰기:
  - execCommand indent 제거
  - 문단 margin-left만 변경하여 폰트/서식 보존
- 정렬도 문단 style만 변경하도록 수정
- ❦ / ❧ 기호 제거
- 문서 기본 꾸밈 → 문서 꾸밈
- 모서리 프레임 기본 위치를 문서 안쪽 18px 이상으로 이동
- 미리보기:
  - 팝업 전체 영역에 한 페이지가 통째로 보이도록 자동 축소
  - 이전/다음 페이지 이동 유지
