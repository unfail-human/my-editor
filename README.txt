추가 기능
- 배경 > 효과
  - 효과 색상 아래 '자동 색상 적용' 체크박스 추가
  - 문서 배경색 / 그라데이션 평균색 / 이미지 평균색을 기준으로 어울리는 효과 색상 자동 계산
  - 직접 색상을 바꾸면 자동 적용은 자동으로 해제

- 기호 > 문서 꾸밈 > 테두리
  - '자동 색상 적용' 체크박스 추가
  - 문서 배경과 조화되는 테두리 색 자동 계산
  - 직접 색상 선택 시 자동 적용 해제

- 기호 > 문서 꾸밈 > 내부 프레임
  - '자동 색상 적용' 체크박스 추가
  - 문서 배경과 어울리면서 테두리와 약간 구분되는 프레임 색 자동 계산
  - 직접 색상 선택 시 자동 적용 해제

자동 색상은 문서 배경을 변경할 때 실시간으로 다시 계산됩니다.
단색 / 그라데이션 / 이미지 배경을 모두 지원합니다.
