MY EDITOR V60

제목 배치
- 중앙 배치 시 본문이 제목/소제목 아래로 확실하게 내려가도록 수정
- 아래 배치 시 제목/소제목을 페이지 하단 쪽으로 크게 이동
- 위/중앙/아래 모두 제목 블록과 본문이 겹치지 않도록 재조정

본문 위치
- 본문을 더 왼쪽으로 이동
- 제목/소제목 아래 선의 시작점과 본문 시작점을 동일한 좌표로 통일
- 오른쪽 끝도 같은 콘텐츠 박스 기준을 사용
- 상단 배치에서는 소제목 선 아래에 작은 간격만 두고 본문 시작
- 1단/2단/3단 모두 같은 좌우 기준선 사용

제목·소제목 섹션
- '제목과 소제목을 첫 페이지에만 표시'만 유지
- 첫 페이지 크게 표시 제거
- 별도 제목 위치/자유배치 설정 제거
- 제목 위치는 '현재 템플릿 세부 설정'에서만 관리

자동 페이지
- 기존 페이지 초과 → 다음 페이지 자동 생성/이동 유지
- 새 페이지 생성 안내 유지
