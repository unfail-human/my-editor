미리보기 저장 디자인
- 미리보기 저장 메뉴를 일반 편집 화면 저장 메뉴와 동일한 클래스/구조로 통일
- 저장 범위 → 파일 형식 2단계 흐름 유지
- 위치만 미리보기 헤더 아래에 맞게 배치

미리보기 복사
- 복사는 파일을 생성하는 기능이 아님
- 현재 미리보기 페이지의 제목/소제목/본문/출처 텍스트를 클립보드에 복사
- 복사 후 안내:
  '현재 페이지의 글 내용이 클립보드에 복사되었습니다.
   Ctrl+V로 붙여넣어 사용할 수 있어요.'
- 안내 표시 시간을 늘림
