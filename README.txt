MY EDITOR V50

새 문서 탭 추가

문서 템플릿
- 일반 문서 A4
- 엽서형
- 카드형
- 정사각형 카드
- 각 형식에서 세로형 / 가로형 선택
- 편집 화면, 미리보기, PNG/JPG/PDF 저장에 같은 비율 적용

본문 배치
- 가로쓰기
- 세로쓰기 (vertical-rl, 오른쪽→왼쪽)
- 1단 / 2단 / 3단
- 단 사이 간격 조절
- 세로쓰기에서는 안정성을 위해 본문 단 나누기를 1단으로 표시

제목 / 소제목
- '제목과 소제목을 첫 페이지에만 표시' 체크박스
- 체크 시 1페이지는 표지처럼 제목/소제목 표시
- 2페이지부터 제목/소제목 숨김
- 제목 위치:
  위 왼쪽 / 위 가운데 / 중앙 / 아래 왼쪽 / 아래 가운데 / 자유 배치
- 소제목 위치:
  제목 바로 아래 / 위 왼쪽 / 위 가운데 / 중앙 / 아래 왼쪽 / 아래 가운데 / 자유 배치
- 자유 배치 시 X/Y 위치 슬라이더

페이지 자동 넘김
- 가로쓰기: 세로 넘침 감지
- 세로쓰기: 가로 넘침 감지
- 템플릿/방향/단 수 변경 시 자동 페이지 재배치

저장
- PDF도 선택한 문서 형식/방향 크기로 저장
- 이미지 저장도 선택한 템플릿 비율로 저장
