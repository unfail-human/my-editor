본문 위치 기능 수정
- '본문 위치 미세 조정' 삭제
- 새 기능: '본문 가로 위치'
- -8% ~ +8% 범위에서 본문 영역 자체를 좌우로 이동
- 왼쪽/오른쪽 정렬 기능과 무관
- 텍스트 정렬을 바꾸지 않고 본문 박스 자체만 움직임
- 템플릿별로 위치값 개별 저장

레이아웃 재정리
- 상단 제목 배치의 과도한 여백 축소
- 제목 → 소제목/실선 → 작은 여백 → 본문 흐름으로 자동 계산
- A4/레터/엽서/카드/와이드/미니/정사각형/티켓별 기본 간격 재조정
- 중앙 배치는 제목 블록 아래에 안전하게 본문 시작
- 하단 배치는 본문이 제목 영역과 겹치지 않게 종료
- 제목/소제목 블록의 행간/여백도 다시 다듬음

자동 페이지
- 본문 가로 위치/제목 간격/제목 크기 변경 시 전체 페이지 재계산
- 초과 내용은 다음 페이지로 자동 이동
- 새 페이지 생성 안내 유지
