MY EDITOR V67

본문 위치
- 왼쪽 여백을 더 줄여 기본 본문 영역 자체를 왼쪽으로 이동
- 기본값: 왼쪽 3%
- 조절 범위: 왼쪽 8% ~ 오른쪽 6%
- 이전처럼 과도하게 왼쪽으로 보내 글자가 잘리는 범위는 제거
- 본문 이동 방식을 left/width 변경에서 transform 방식으로 수정
- 글자 폭이 잘리거나 먹히는 현상 방지
- 기호는 계속 본문 위치와 독립

설명 문구
- '본문 영역의 위치를 조정합니다.'로 단순화

제목 폭
- 제목 크기 바로 아래에 '제목 폭' 추가
- 45% ~ 96%
- 제목과 소제목 폭이 함께 변경
- 왼쪽/가운데/오른쪽 제목 배치에 맞춰 폭 기준 위치 자동 계산
- 템플릿별로 제목 폭 저장
