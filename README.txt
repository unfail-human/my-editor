MY EDITOR V75

문서 여백 실시간 미리보기
- 팝업을 연 상태에서 좁게/보통/넓게 선택 즉시 실제 문서에 반영
- 용지 여백 mm 입력 즉시 실제 문서에 반영
- 머리말/바닥글 mm 입력 즉시 반영
- 본문 내부 여백 mm 입력 즉시 반영
- 페이지 분량도 짧은 지연 후 자동 재계산

적용 / 취소
- 적용: 현재 미리보기 값을 실제 템플릿 설정으로 저장
- 취소 / X: 팝업 열기 전 여백 상태로 완전히 복원
- 보통으로 초기화도 즉시 문서에서 미리보기

팝업 디자인
- 팝업 외곽선 강화
- 헤더 하단 구분선
- 각 설정 섹션 구분선 강화
- 본문 여백 영역 별도 배경/테두리
- 입력 포커스 표시 개선

기호
- V74의 중앙 고정 유지
- 문서 여백/본문 위치/본문 여백에 영향받지 않음
