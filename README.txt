MY EDITOR V10

이번 버전은 기능 연결을 새로 정리한 재구축 버전입니다.

변경:
- 본문 위 글자 편집 툴바 완전 제거
- 오른쪽: 글 편집 / 배경 / 기호
- 왼쪽 슬롯 카드: 클릭 = 슬롯 전환 + 현재 슬롯 자동 저장
- 슬롯의 ⋯ = 저장 / 이름변경 / 복제 / 위아래 이동 / 삭제
- 상단 복사 버튼 1개만 유지
- 미리보기 / 저장 별도 유지
- 글 편집 기능의 이벤트를 모두 오른쪽 패널에 새로 연결
- 기호 탭에 종이결 / 줄지 / 모눈 / 점지 / 테두리 음영 등 지면 효과
- 장식 기호 및 모서리/구분선/상하 표식 추가
