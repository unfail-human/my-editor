MY EDITOR V23

긴급 안정화 버전.

- 배경/기호/미리보기 등 UI 전체가 멈추던 런타임 오류 제거
- 모든 JS의 literal DOM ID가 실제 HTML에 존재하는지 자동 검사 완료
- Node JS 문법 검사 통과

슬롯
- 슬롯명은 제목 입력과 자동 연동
- 제목이 비면 새 문서 01, 02... 형식
- 슬롯 비우기 → 슬롯 삭제
- 삭제 뒤 슬롯 번호는 현재 순서대로 01, 02, 03... 표시
- 새 슬롯 추가/슬롯 이미지/드래그 순서 변경 유지

본문
- 일반 타이핑 중 renderAll을 호출하지 않도록 변경
- 커서가 갑자기 본문 맨 위로 이동하는 문제 수정
- 넘칠 때만 다음 자동 페이지 생성/이동
- 삭제로 공간이 생기면 다음 자동 페이지의 문단을 앞 페이지로 당김
- 폰트/간격 변경 때만 전체 재배치

형광펜
- inline mark 방식으로 적용
- 지우기는 선택 영역과 겹치는 형광펜 요소의 배경을 제거
- 형광펜 지우기 후 다른 기능이 정지하는 문제 방지

배경
- 지면 효과 → 효과
- 효과 색상 지정 추가

문서 꾸밈
- 테두리 투명도
- 내부 프레임 투명도

미리보기
- 본문 hard clip
- 다음 페이지 글씨가 이전 페이지 아래로 새지 않도록 수정
- 페이지 전체가 더 여유 있게 보이도록 기본 맞춤 축소
- 확대/축소 유지

GitHub에서는 index.html / style.css / script.js를 교체하세요.
루트 폰트 파일은 그대로 유지하면 됩니다.
