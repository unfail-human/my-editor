제목 + 소제목 레이아웃 개선
- 제목/소제목 블록 좌우 폭 확대
- 제목과 소제목이 같은 넓은 기준선을 사용
- 소제목 아래의 얇은 라인을 유지하면서 여백을 더 넉넉하게 조정
- 본문과 제목 블록 사이 간격 확대
- 가로형에서도 넓은 헤더 블록 유지
- 카드/엽서/티켓 등 작은 문서는 크기에 맞춰 제목 크기 자동 축소

단 나누기 + 제목 자동 배치
- 1단: 사용자가 선택한 제목 위치 유지
- 2단/3단: 제목+소제목을 페이지 전체 상단 중앙에 자동 배치
- 본문은 제목 블록 아래에서 2단/3단으로 시작
- 2단/3단일 때 제목 크기도 레이아웃에 맞게 자동 조정
- 구분 장식은 기존처럼 현재 단 안에서 중앙 정렬

문서 템플릿 정리
- 소형 문서(A5) 삭제
- 노트형(B5) 삭제
- 유지:
  A4 / 레터형 / 엽서형 / 카드형 3:2 / 와이드 카드 16:9 /
  미니 카드 4:3 / 정사각형 카드 / 티켓형
