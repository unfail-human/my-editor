MY EDITOR V53

단락 구분 장식
- 가로쓰기 1단: 문서 본문 폭 전체 기준으로 가운데 정렬
- 가로쓰기 2단/3단: 삽입된 문단이 속한 '그 단'의 폭 안에서 가운데 정렬
- 구분선도 현재 단 너비만 사용
- column-span을 사용하지 않아 여러 단 전체를 가로지르지 않음

제목 + 소제목 / 본문
- 왼쪽 배치 또는 자유 배치의 경우 제목 묶음 X 위치와 본문 시작 X 위치를 동일하게 맞춤
- 가운데 배치는 본문도 대칭 여백으로 중앙 영역에 배치
- 제목과 본문 사이 간격을 확대
- 첫 페이지 크게 표시 시 간격을 추가 확대
- 가로 템플릿과 카드형은 높이에 맞게 별도 간격 사용

자동 다음 페이지
- A4뿐 아니라 가로형/엽서/카드/티켓 등 모든 템플릿에서 넘침 감지
- 일반 문단 단위 자동 이동 유지
- 문단 하나가 페이지 전체보다 길어도 텍스트 지점을 찾아 문단을 둘로 나누어 다음 페이지로 자동 이동
- 레이아웃/방향/단 수 변경 시 전체 자동 페이지 재배치
- 삭제/공간 확보 시 다음 자동 페이지의 내용을 앞 페이지로 다시 당겨옴
