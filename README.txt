소제목 자동 정렬
- 왼쪽 제목: 소제목은 제목보다 약 1.15% 안쪽에서 시작
- 가운데 제목: 제목/소제목 모두 정확히 중앙 유지
- 오른쪽 제목: 소제목 끝점을 제목보다 약 1.15% 안쪽으로 조정
- 소제목이 제목보다 너무 왼쪽으로 튀어나와 보이던 기본값 수정

여백 음수 입력
- 용지 여백 위/아래/왼쪽/오른쪽: -30mm까지 허용
- 머리말/바닥글: -30mm까지 허용
- 본문 내부 여백 위/아래/왼쪽/오른쪽: -30mm까지 허용
- 실시간 미리보기 유지
- 내부 계산은 안전 하한을 두어 레이아웃이 완전히 깨지는 것을 방지
