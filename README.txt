엽서형~티켓형 레이아웃 구조 수정
- 제목/소제목/본문이 서로 다른 기준선을 쓰던 구조 제거
- 엽서형 / 카드형 / 와이드 카드 / 미니 카드 / 정사각형 / 티켓형은
  제목 + 소제목 + 본문을 하나의 공통 콘텐츠 프레임 안에 배치
- 본문이 제목보다 바깥으로 튀어나오는 현상 수정
- 작은 템플릿에서 제목이 중앙으로 밀리거나 비뚤어져 보이는 현상 수정
- 오래된 free-position 좌표가 작은 템플릿 상단 배치에 영향을 주지 않도록 차단
