제목/소제목

- 제목 뒤 6px 간격으로 소제목 배치
- 제목과 소제목의 합친 행 아래에 하나의 긴 실선
- 제목/소제목 텍스트 길이를 실제 측정해서 위치 자동 계산
- 왼쪽/가운데/오른쪽 제목 배치도 그룹 단위로 계산
