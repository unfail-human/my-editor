MY EDITOR V18

- 글자색은 선택 영역에 바로 적용
- 글꼴 적용 = 폰트/크기/글자색 페이지 전체 일괄 적용
- 간격 적용 = 간격 섹션 페이지 전체 일괄 적용
- 링크명 + 링크 주소 팝업
- 슬롯 카드 드래그 순서 변경
- 슬롯 편집 팝업: 저장/이름/복제/비우기
- 슬롯 이미지 선택 추가 가능
- 슬롯 비우기는 기본 슬롯으로 초기화
- 미리보기는 편집 문서 크기/비율을 복제한 뒤 화면 안에 자동 맞춤
- 본문 내부 스크롤 제거
- 본문 넘침 시 문단 단위로 다음 페이지 자동 생성 및 자동 이동
- 자동 생성 페이지는 앞 페이지에 공간이 생기면 자동으로 문단을 되돌림
- 수동 페이지는 자동 합치지 않음
- 저장은 고정 페이지 크기로 캡처
