MY EDITOR V52

단락 구분선
- 기호 > 무단 구분에 '구분선 함께 사용' 체크박스 추가
- 체크 시 구분 장식 양옆에 아주 얇은 1px 선 표시
- 구분선 투명도 조절 가능
- 기존에 삽입된 구분 장식에도 설정 즉시 반영
- 미리보기 / 저장 파일에도 동일하게 반영

뒤로가기 / 다시 실행
- 기존 브라우저 기본 Ctrl+Z 대신 MY EDITOR 자체 기록 사용
- 약 2.5초 단위로 입력 내용을 묶어서 기록
- Ctrl+Z: 약 2~3초 전 상태 단위로 복원
- Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행
- 제목 / 소제목 / 본문 입력 모두 기록
- 페이지를 바꾸면 해당 페이지 기준으로 새 기록 시작
- 최대 약 80개 상태 보관
