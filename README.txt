MY EDITOR V31

배포 기본값
- 새 방문자는 코드에 고정된 배포 기본 설정으로 시작
- Pretendard 12pt / 기본 글자색 #3f3d3b / 행간 1.25
- 흰색 단색 문서 배경
- 효과 없음 / 자동 색상 적용 ON
- 테두리/프레임 없음 / 자동 색상 적용 ON
- 기본 슬롯 4개
- 각 사용자의 작성 내용과 설정은 각자 브라우저 localStorage에 저장되어 서로 공유되지 않음

내 설정
- 설정 내보내기: 현재 슬롯의 글꼴/간격/배경/효과/테두리/프레임/구분 장식 설정을 JSON으로 저장
- 설정 불러오기: 해당 JSON을 현재 슬롯 전체 페이지에 적용
- 활성 사용자 폰트가 있으면 폰트 파일을 설정 JSON에 포함
- 활성 배경 이미지가 있으면 이미지 파일을 설정 JSON에 포함
- 글 내용/슬롯 내용은 설정 파일에 포함하지 않음
- 전체 백업/백업 불러오기는 기존대로 유지

기호
- '문단 구분 장식' 이름을 '무단 구분'으로 변경
- 구분 문자를 넣을 때 위/아래에 각각 한 줄 공백을 자동 삽입
