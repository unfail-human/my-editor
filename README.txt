MY EDITOR V101 — 저장 시 제목 잘림 수정

원인
- 미리보기의 제목/소제목은 native <input> 요소라 브라우저 화면에서는 정상
- html2canvas가 일부 한글 폰트의 input 글자 영역을 캡처할 때 상단/하단 glyph를 잘라냄
- 특히 굵은 한글 제목에서 증상이 크게 나타남

수정
- 미리보기 레이아웃은 그대로 유지
- 저장 시에도 미리보기와 같은 clone/좌표 사용
- 문서가 완전히 렌더된 뒤 저장 직전에만 제목/소제목 input을 일반 div 텍스트 레이어로 변환
- 변환 시 getBoundingClientRect()로 미리보기의 실제 위치/폭을 그대로 복사
- 폰트, 크기, 굵기, 자간, 정렬, 색상도 computed style 그대로 복사
- 높이만 폰트 크기의 최소 1.45배까지 안전하게 확보
- overflow visible로 한글 획이 위/아래에서 잘리지 않게 수정
- PNG/JPG/PDF 모두 같은 capture 경로 사용
- 본문/기호/쪽번호/출처 위치는 변경하지 않음
