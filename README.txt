MY EDITOR V51

수정사항

가로형 제목/본문 겹침 수정
- 제목/소제목 위치에 따라 본문 영역이 자동으로 비켜감
- 위쪽 배치 → 본문 위 여백 자동 증가
- 중앙 배치 → 본문 아래 공간 확보
- 아래쪽 배치 → 본문 하단 여백 자동 확보
- 가로형에서는 제목 폭을 고려해 여백을 조금 더 크게 적용

제목 + 소제목 통합 배치
- 제목과 소제목 위치 설정을 하나로 통합
- 둘이 항상 한 묶음으로 같이 이동
- 위치:
  위 왼쪽 / 위 가운데 / 정중앙 / 아래 왼쪽 / 아래 가운데 / 자유 배치
- 자유 배치 X/Y 슬라이더도 하나만 사용
- 소제목은 제목 바로 아래에 자동 배치

첫 페이지 옵션
- 제목과 소제목을 첫 페이지에만 표시
- 바로 아래에:
  첫 페이지에서 제목·소제목 크게 표시
  체크박스 추가
- 크게 표시하면 1페이지 제목/소제목 크기가 자동 확대
- 본문 여백도 확대된 제목 크기에 맞춰 자동 조정

기존 v50 저장 데이터
- titlePosition/titleX/titleY 설정은
  headingPosition/headingX/headingY로 자동 변환
