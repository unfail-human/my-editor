MY EDITOR V98 — 실제 적용 복구판

원인
- V97 currentLayout() 안에서 `s`를 선언하기 전에 `s.layout`을 읽는 코드가 들어가
  페이지 초기화 시 ReferenceError가 발생했습니다.
- 이 때문에 문서 템플릿, 기본형 방향, 기존 양식 데이터 등 이후 UI 동기화가 실행되지 않았습니다.

수정
- V95를 기준으로 다시 제작
- currentLayout() 실행 오류 제거
- 티켓형만 선택 목록에서 제거
- 일반 문서 A4 / 레터형 / 엽서형 / 카드형 3:2 / 와이드 16:9 /
  미니 카드 4:3 / 정사각형 카드 모두 유지
- 기존 페이지 글/슬롯/기본 양식 데이터는 수정하지 않음
- 과거 티켓 슬롯은 페이지 내용을 유지하고 template 값만 카드형 3:2로 변경

기본형
- 엽서형 / 카드형 3:2 / 와이드 카드 16:9 / 미니 카드 4:3 / 정사각형 카드
- 선택 즉시 landscape로 먼저 정규화한 뒤 저장/렌더
- 방향 UI는 '기본형' 한 항목만 표시하며 비활성화
- 일반 문서와 레터형만 세로형 / 가로형 선택 가능
