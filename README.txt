변경사항
- 오른쪽 패널에서 '미리 보기' 탭 제거
- 편집기 상단에 독립 기능으로 배치:
  복사 / 미리보기 / 저장

- 저장: 기존 PNG / JPG / PDF / TXT 저장 메뉴 유지
- 미리보기: 큰 팝업으로 문서만 깔끔하게 표시
- 미리보기 화면 안에서도 복사 / 저장 가능
- 오른쪽 패널은 폰트 편집 / 슬롯 편집 / 문서 배경 3개로 정리
