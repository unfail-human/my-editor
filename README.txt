MY EDITOR V27

수정사항

형광펜 지우기
- 선택한 부분만 형광펜 제거
- 선택 영역 앞/뒤의 형광펜은 그대로 유지
- 선택 경계를 텍스트 오프셋 기준으로 다시 계산해서 부분 선택을 정확히 분리
- 형광펜 요소 전체를 통째로 지우는 방식 제거

들여쓰기
- 일반 문단:
  첫 줄만 약 2~3칸 정도 들여쓰기
  text-indent 방식이라 문장 전체가 옆으로 밀리지 않음
- 목록(ul/ol/li):
  기존처럼 목록 항목 전체가 안쪽으로 들어감
  들여쓰기/내어쓰기 모두 지원

검증
- Node JavaScript 문법 검사 통과
- JS DOM ID 참조 누락 없음

GitHub에서는 index.html / style.css / script.js를 v27로 함께 교체하세요.
