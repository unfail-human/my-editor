MY EDITOR V56

기본 템플릿
- 새 슬롯/기본 문서는 A4 + 세로형으로 시작
- 기존 슬롯은 기존 선택값을 유지

템플릿별 개별 설정
각 템플릿마다 따로 저장:
- 가로 / 세로 방향
- 제목 크기
- 제목 + 본문 사이 간격
- 제목 + 소제목 위치
템플릿을 바꾸면 해당 템플릿에서 마지막으로 사용한 설정을 다시 불러옴

문서 리사이징
- A4/레터/엽서/카드/와이드카드/미니카드/정사각형/티켓 각각 고유 크기/비율 사용
- 편집 화면에서 템플릿마다 종이 크기가 명확히 달라짐
- 가로/세로 방향도 각 템플릿별로 기억

글 잘림 방지
- 제목/소제목은 overflow visible
- 본문 하단에 안전 여백 추가
- 레이아웃 변경 후 render → reflow 순서로 페이지 분량 다시 계산
- 내용이 페이지를 초과하면 자동 다음 페이지로 이동
- 페이지 밖으로 글이 잘린 채 남지 않도록 자동 페이지 재배치 우선
